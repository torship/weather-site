# 🌦️ Weather Website

A simple and responsive weather website that provides real-time weather information for any city using a clean and user-friendly interface.

🔗 **Live Demo:** https://torship.github.io/weather-site/

---

## 🚀 Features

- 🌍 Search weather by city name  
- 🌡️ Displays temperature, weather condition, humidity, and wind speed  
- 🎨 Clean and responsive UI  
- ⚡ Fast and lightweight  
- 📱 Mobile-friendly design  

---

## 🛠️ Technologies Used

- **HTML5**  
- **CSS3**  
- **JavaScript**  
- **Weather API** (e.g., OpenWeatherMap or similar)
